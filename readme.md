# 🐄 Lactose Fighters

**Lactose Fighters** is a *Shoot’em Up-like* action game developed for the **Pirate Software Game Jam 2025** by **Farinaceos**.

You play as a cow — the last line of defense against the lactose intolerant — using milk as your weapon. 🥛

---

## 🎮 Game Summary

You are a menace! A weapon against (lactose) intolerance!

As a cow, you must defeat enemies using milk while managing your resources:

- Each shot consumes milk  
- Defeat enemies to gain points  
- Refill your milk by eating grass  
- Race against time to achieve high scores

## 🧠 Game Concept

### Gameplay Overview

- Top-down 2D perspective  
- Four-directional movement and shooting  
- Limited milk resource system  
- Time-based gameplay (Time Attack)  

### Theme Interpretation

Unlike traditional shooters:

- You **are the weapon**  
- Your milk is your ammo  
- Resource management is key to survival  

---

## ⚙️ Core Mechanics

| Mechanic      | Description |
|--------------|------------|
| Movement     | Move in a 2D environment using keyboard or controller |
| Shooting     | Fire milk in four directions, consuming resources |
| Refill       | Eat grass dropped by mobs or spawned randomly |
| Time Attack  | Game ends when the timer reaches zero |
